# Nexus Hub | Blade Ball
> Made by MinhScripts + Greenic Scripts
> Version 1.1

Nexus Hub is a lightweight and optimized Blade Ball utility hub designed for smooth performance and consistent execution.

---

## Features
- ⚡ Auto Parry
- ⚔️ Auto Spam Parry
- 🎯 Triggerbot
- 🗡️ Skin Changer (Real sword cloning method)
- 👤 Player Cosmetics (Headless + Korblox)
- 🌀 Spinbot
- ✈️ Fly
- 🎵 Hit Sounds
- 🔁 Lobby Auto Parry
- 🕹️ Manual Spam
- 🌐 Wrong game redirect (auto joins Blade Ball)
- More coming soon in v1.2!
